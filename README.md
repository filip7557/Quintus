# 🧰 Quintus

**Quintus** je manji projekt koji predstavlja **web aplikaciju** za instalatersku tvrtku.  
Aplikacija služi kao **online prezentacija usluga**, ali i kao **platforma za slanje zahtjeva majstoru** putem fotografija i osnovnih informacija.

---

## 🚀 Funkcionalnosti

- 🏠 Prikaz informacija o instalaterskoj tvrtki  
- 🔧 Pregled ponude usluga i kontakata  
- 📸 Slanje zahtjeva za majstora uz mogućnost dodavanja fotografija  
- 📬 Automatsko spremanje i obrada zahtjeva na backendu  

---

## 🖥️ Tehnologije

### Backend
- **C# .NET 9.0**
- **Entity Framework Core**
- **PostgreSQL** (relacijska baza podataka)
- **REST API** za komunikaciju s frontendom

### Frontend
- **Next.js (React)**  
- **JavaScript**
- **Axios** za komunikaciju s API-jem
